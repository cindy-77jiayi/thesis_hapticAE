\chapter{Discussion and Conclusion}

\section{Discussion}

This thesis shows that vibrotactile feedback for temporal visual events is best treated as a structured generation problem. A visual event such as a confirmation, error, notification, or refresh sequence carries meaning through time: it has a beginning, a moment of emphasis, a duration, and a completion state. The user study supports this framing. Participants did not evaluate vibrations only by intensity. Their ratings, selections, written explanations, and follow-up survey responses consistently emphasized timing, rhythm, semantic fit, and event appropriateness. These findings motivate a haptic generation pipeline that preserves event structure before producing low-level actuator commands.

Semantic VAE contributes such a pipeline. It converts visual state sequences into semantic haptic event plans, uses a behavior atlas to guide search in a learned VAE latent space, composes generated waveform chunks into a two-second timeline, and exports the result to an ERM-ready playback sequence. The strongest empirical result for Semantic VAE is reliability. It was competitive in average ratings, significantly more meaningful than weaker baselines, and selected as the worst match least often. This pattern matters because practical haptic generation systems need to avoid clearly inappropriate feedback, especially when designers or end users may not inspect every generated waveform in detail. Semantic VAE therefore demonstrates a stable visual-event-grounded generation strategy.

At the same time, the study shows that semantic grounding alone is not enough to determine the best haptic response. Random-Plan VAE achieved the highest overall ratings while using the same VAE, behavior atlas, latent search, timeline mixer, and ERM preprocessing pipeline as Semantic VAE. Its event plan was generated independently of the UI flow, yet participants often preferred its outputs. This result is one of the central findings of the thesis. It shows that the VAE-atlas backend can generate strong haptic candidates and that a broader structured design space can contain responses that users prefer over conventional UI-grounded plans.

The combination of these results changes how visual-to-haptic generation should be understood. Semantic planning is valuable because it organizes generation around event meaning and reduces failure risk. However, the preferred haptic response for a visual event is not a single deterministic target. Participants differed in whether they preferred short or sustained success cues, sharp or smooth error feedback, subtle or salient notifications, and continuous or punctuated refresh responses. Visual semantics constrains the design space, but user preference, context, and temporal style shape which region of that space feels best.

This interpretation also clarifies the role of the language-model planner. In this thesis, the GPT-4.1 planner is a replaceable implementation of the semantic event layer. It was useful for turning UI image sequences into structured haptic plans, but its outputs likely reflect existing interaction conventions and common prompt-based assumptions about UI feedback. Those conventions made Semantic VAE stable, but they may also have limited exploration. Future systems should therefore learn from richer data about both visual events and haptic design judgments. The goal should not only be to map visual events to haptic labels, but also to understand how people interpret a generated haptic pattern, whether they can infer the intended event from it, and how designers can use those interpretations as input to the next generation cycle.

The final system also reflects a methodological choice made during development. An earlier direction attempted to control the VAE latent space through a small number of semantic control axes, including PCA-style factors intended to represent properties such as amplitude, frequency, onset, modulation, and temporal profile. That approach was attractive because it suggested direct semantic sliders from visual analysis to waveform generation. In practice, the available dataset was too small and heterogeneous, the relationship between waveform features and semantic labels was not cleanly linear, and the tradeoff between reconstruction quality, interpretability, and controllability became too large. The atlas-guided search used in the final system is a stronger fit for this project because it preserves learned waveform variation while giving the system interpretable behavior regions and feature-based scoring.

Together, these findings argue for haptic generation systems that combine semantic structure with generative exploration. A system should understand the visual event, but it should also generate and compare multiple plausible haptic interpretations. For temporal visual events, the most useful output may be a structured set of candidates that differ in rhythm, salience, duration, and smoothness, rather than a single waveform presented as the correct answer.

\section{Design Implications}

The results suggest several implications for future haptic generation systems and design tools.

First, temporal visual events should be represented as temporal haptic events. A visual transition is more than a label such as success, error, notification, or loading. It includes ordered stages, moments of emphasis, and expectations about when feedback should begin, persist, or resolve. The strong role of timing and rhythm in both the qualitative explanations and the follow-up survey supports this design principle. Haptic generation systems should therefore preserve onset, duration, repetition, progression, and completion as first-class design variables.

Second, semantic planning should be treated as a constraint for exploration. The semantic event plan in this thesis made generation inspectable and reduced clearly mismatched outputs, but the user study also showed that multiple haptic interpretations can be valid for the same visual event. A design tool should expose the planned haptic events to the designer, allow edits to semantic roles or timing, and generate multiple candidates around the plan. This would let designers use semantic planning as a starting point while still exploring alternatives in salience, rhythm, smoothness, and duration.

Third, haptic generation should support comparison and selection, not only synthesis. The best-performing and least-rejected stimuli came from different methods, which suggests that evaluation and choice are part of the design process. A practical tool could present a small set of diverse candidates, allow users or designers to replay them with the visual event, and record preference feedback. These selections could then guide the next round of latent search or planner refinement. In this sense, haptic generation can become an interactive loop between visual interpretation, candidate generation, and human judgment.

Fourth, generated haptics need to be designed for the playback hardware. The study used a shared ERM preprocessing pipeline so that all methods were compared under the same actuator constraints. This step is important because a waveform that looks plausible as a signal may feel different when converted to discrete motor drive values. Future systems should keep actuator characteristics visible in the design process, especially when moving between ERM motors, LRA actuators, voice-coil devices, or other haptic hardware.

Finally, designers may benefit from tools that support reverse interpretation. If a generated haptic pattern is intended to represent confirmation, warning, progress, or arrival, a useful system should help test whether users can infer that intent from the vibration. This shifts haptic generation from producing signals that match a prompt to producing signals that communicate an intended event. Such reverse checks could provide valuable training data for future visual-to-haptic models and help close the loop between designer intent, generated waveform, and user interpretation.

\section{Limitations}

This thesis has several limitations that define the scope of the current system and evaluation.

The first limitation is the size and coverage of the haptic waveform data. The VAE was trained on 793 waveform files, which is sufficient for a thesis-scale prototype but small compared with the diversity of haptic signals that appear across devices, applications, and interaction contexts. The behavior atlas also involved manual curation. This curation improved the reliability of prototype anchors, especially when automatically selected class centers decoded into perceptually ambiguous waveforms, but it also introduced human judgment into the construction of the generation space. A larger and more systematically labeled dataset would support more reliable behavior classes, stronger evaluation of latent structure, and better generalization beyond the current atlas.

The second limitation is the scope of the visual events. The user study used four controlled UI flows: Payment Confirmation, Failed Submission, Notification Received, and Pull to Refresh. These flows cover common HCI feedback scenarios and provide a controlled basis for comparing methods, but they represent only one class of temporal visual events. The broader problem includes video events, AR and VR scene changes, physical object interactions, robot motion, and multi-step workflows. The current schema and prompt can be adapted to other domains, but the study results should be interpreted as evidence from controlled UI event sequences rather than as a complete evaluation of all temporal visual haptic generation.

The third limitation is the semantic planner. The system used GPT-4.1 with a schema-designed prompt to produce haptic event plans from UI image sequences. This made the semantic layer easy to prototype and inspect, but it also tied the planner to the assumptions of the model, prompt, and schema. In particular, the planner may reproduce familiar UI haptic conventions and underexplore less conventional but still preferred haptic interpretations. This limitation is visible in the study: Semantic VAE was stable and rarely rejected, while Random-Plan VAE sometimes produced more highly preferred candidates by exploring a broader structured space. A future planner should be learned or adapted from richer haptic preference data rather than relying primarily on general-purpose language-model priors.

The fourth limitation concerns the analysis of preference and confidence. Best and worst selections were collected at the flow level, and confidence was reported once in the follow-up survey as a participant-level self-assessment. The confidence-weighted sensitivity check showed that the main worst-selection result for Semantic VAE was robust, but confidence was not collected separately for each individual selection. Future studies could ask for confidence at the moment of each best or worst choice, or use forced-choice comparisons to model preference strength more directly.

The qualitative analysis also has limits. Written explanations were short and were coded using a codebook-based process. This is useful for identifying recurring themes such as timing, rhythm, semantic fit, intensity, and randomness, but it cannot capture the full reasoning process behind each participant's haptic preferences. Interviews, think-aloud protocols, or iterative design sessions would provide deeper insight into how users interpret haptic feedback and how designers might revise generated candidates.

Finally, the hardware evaluation was limited to an ERM motor driven through a DRV2605L. This actuator choice was appropriate for a deployable prototype and allowed all study stimuli to be played through the same preprocessing pipeline. Other actuators may support different frequency ranges, response times, amplitudes, and tactile qualities. Extending the system to LRA motors, voice-coil actuators, wearable devices, or multi-actuator arrays would require new preprocessing and evaluation.

\section{Future Work}

The most important direction for future work is to extend the system beyond short UI flows to broader temporal visual events. The current pipeline already uses an ordered visual input and an event-level semantic plan, which makes it naturally compatible with video key frames, animation sequences, AR or VR scene transitions, physical object interactions, and longer multi-step workflows. Future systems could sample key frames from a video, identify meaningful state changes, and generate haptic event plans that preserve the timing and salience of those changes. This would move the approach from controlled UI feedback toward general temporal visual haptic generation.

A second direction is to build an interactive design tool around the pipeline. The current prototype was built for evaluation, but the system components suggest a designer-facing workflow: import a visual event, inspect the generated semantic haptic plan, edit event roles or timing, generate multiple haptic candidates, and compare them through live playback. The behavior atlas could become a visual design space where designers browse behavior families, select anchors, and adjust generated candidates. Such a tool would make the semantic layer useful not only for automation, but also for human-in-the-loop authoring.

Future work should also collect more haptic data. The results show that the VAE-atlas backend can generate strong candidates, but larger datasets are needed to learn richer behavior classes and more reliable latent structure. Additional data should include not only waveform examples, but also semantic labels, perceptual ratings, context descriptions, and user or designer judgments. Especially valuable would be paired data connecting visual events, intended haptic meanings, generated waveforms, and user interpretations. This kind of dataset would support learned planners that move beyond general language-model conventions.

Personalized and preference-aware generation is another important direction. The user study showed that participants differed in their preferred balance of salience, rhythm, duration, and smoothness. A future system could learn user-specific or context-specific preferences from selections, ratings, or quick calibration tasks. Instead of producing one default haptic response for a visual event, the system could generate several candidates and gradually adapt toward the user's preferred region of the latent space.

Finally, future work should evaluate the pipeline across more haptic hardware. ERM motors are common and easy to deploy, but they represent only one actuator family. LRA motors, voice-coil actuators, wearable arrays, and multi-actuator devices can express different temporal and spatial qualities. Supporting these devices would require actuator-specific preprocessing, calibration, and perceptual evaluation. A hardware-aware version of the pipeline could preserve the same semantic event representation while adapting waveform generation and export to the capabilities of each device.

\section{Conclusion}

This thesis presented a semantic VAE pipeline for generating vibrotactile feedback from temporal visual events. The system represents visual transitions as semantic haptic events, uses a behavior atlas to guide VAE latent search, composes generated waveform chunks into a two-second event timeline, and exports the result to an ERM-ready playback sequence. This pipeline connects visual interpretation, haptic intent, generative waveform synthesis, temporal composition, and physical playback in one end-to-end system.

The 27-participant user study showed that Semantic VAE produced meaningful, competitive, and reliable haptic feedback for controlled UI event sequences. It improved meaningfulness over weaker baselines and was selected as the worst match least often, making reliability one of its clearest strengths. The study also showed that Random-Plan VAE achieved the highest overall ratings, demonstrating the strength of the VAE-atlas generation backend and the value of exploring a broader structured haptic design space.

The central conclusion is that visual-to-haptic generation is not a one-to-one mapping from event semantics to a single best vibration. Temporal visual events constrain haptic design, but user preference depends on rhythm, timing, salience, duration, smoothness, and context. Semantic planning is therefore most powerful when paired with generative exploration and human feedback. This thesis contributes a step toward haptic generation systems that are structured enough to be interpretable, flexible enough to support multiple valid designs, and concrete enough to be deployed on real haptic hardware.
